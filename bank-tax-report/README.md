# bank-tax-report — 신한은행 기업 거래·이체 + 홈택스 세금계산서 → 엑셀

법인 공동인증서 하나로 아래를 한 번에 조회해서 **엑셀 파일 1개**로 저장합니다(기본: 오늘 포함 최근 7일).

| 시트 | 내용 | 출처 |
|---|---|---|
| 요약 | 기간, 입금/출금 합계, 발급·수취 세금계산서 건수·공급가액·세액 | — |
| 계좌거래내역 | 신한은행 기업 계좌 거래 | 신한은행 기업뱅킹 |
| 출금내역 | 위 거래 중 출금 건 | 신한은행 기업뱅킹 |
| 이체결과(은행) | 이체결과조회 엑셀 그대로(이체일시·받는분·금액·수수료·처리결과 등) | 신한은행 기업뱅킹 |
| 세금계산서_발급(매출) | 같은 기간에 발급한 전자세금계산서 | 홈택스 |
| 세금계산서_수취(매입) | 같은 기간에 받은 전자세금계산서 | 홈택스 |

**맥 앱**(「거래·세금계산서 조회.app」)으로 실행합니다. 인증서 비밀번호는 어디에도 저장하지 않습니다.

신한은행은 **화면 반자동**이 기본입니다(가입·API 키 불필요):
앱이 크롬 창으로 신한 기업뱅킹을 열면 **로그인만 직접** 하고, 그다음
조회 → 거래내역조회 → 기간 → 조회 → 엑셀저장은 앱이 화면 글자를 보고 눌러서 받은 엑셀을 읽습니다.
자동 클릭이 막히면 그 크롬 창에서 직접 엑셀을 받기만 하면 이어서 진행됩니다.
(다른 방식: 미리 받아 둔 엑셀 파일 고르기, 또는 CODEF API)

## 맥에서 설치·사용

1. **터미널**(응용 프로그램 → 유틸리티 → 터미널)을 열고 아래 한 줄을 붙여 넣고 엔터:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/ssizzkim/claude-mobile/refs/heads/main/bank-tax-report/bootstrap_mac.sh | bash
   ```

   앱 파일, 필요하면 앱 전용 Python(관리자 암호 불필요), 패키지를 모두 내려받아 설치하고
   `/Applications/거래·세금계산서 조회.app` 을 만든 뒤 바로 실행합니다(몇 분 걸림).
   다시 실행하면 최신 버전으로 업데이트됩니다.
   (압축 파일로 받았다면 폴더 안의 `install_mac.command` 를 **오른쪽 클릭 → 열기** 해도 같습니다.)
   크롬이 없으면 함께 설치합니다.
2. 앱에서 공동인증서 고르기(`~/Library/Preferences/NPKI` 와 USB의 `NPKI` 폴더에서 자동으로 찾음, 홈택스용) →
   비밀번호 → 기간(기본 최근 7일, [지난주(월~일)] 버튼) → **[조회하고 엑셀 저장]**.
3. 크롬 창이 뜨면 신한 기업뱅킹에 **직접 로그인**. (처음 한 번은 신한 보안 프로그램 설치 안내가 나오면 설치)
   로그인이 자동으로 확인되지 않으면 앱의 **[다음 ▶]**.
4. **처음 한 번만**: 앱 로그에 안내가 나오면 크롬에서 직접
   **거래내역조회 → 조회 → 엑셀저장**, 이어서 **이체결과조회 → 조회 → 엑셀저장**을 합니다.
   앱이 그 클릭 순서를 기억합니다(필요 없는 자료는 **[다음 ▶]**으로 건너뛰기).
5. **다음부터는** 로그인만 하면 앱이 기억한 순서대로 누르고, '조회' 직전에 기간을 넣고, 두 엑셀을 받아
   홈택스 자료와 합친 엑셀을 저장 폴더에 만들고 엽니다.
   - 은행 화면이 바뀌어 재생이 실패하면 다시 한 번 보여 달라고 안내하고 새 순서를 기억합니다.
     **[클릭 순서 다시 배우기]**로 직접 지울 수도 있습니다.

**문제가 생기면**: 진행 기록이 `~/Library/Application Support/BankTaxReport/최근실행기록.txt` 에 남습니다(다운로드 시작·완료·차단 포함). 이 파일을 보내 주세요.

**저장 위치**: 앱의 *저장 폴더*(기본 `문서/거래_세금계산서`, **[변경…]**으로 데스크탑 등 선택) 아래에
합친 엑셀과 `은행원본/<조회시각>/거래내역·이체결과/` 원본 파일이 함께 저장됩니다. **[저장 폴더 열기]**로 바로 열 수 있습니다.
`~/데스크탑`처럼 한글 이름으로 적어도 실제 데스크탑에 저장됩니다. 저장이 안 되면 시스템 설정 → 개인정보 보호 및 보안 →
파일 및 폴더에서 이 앱의 접근을 켜 주세요.

- **[데모 엑셀]**: 인증서·인터넷 없이 가짜 데이터로 엑셀 모양을 먼저 볼 수 있습니다.
- 은행 조회 방식 **받아 둔 엑셀 파일**: 기업뱅킹에서 직접 받은 거래내역 파일(xls/xlsx/csv)을 골라 합칩니다.
- 은행 조회 방식 **CODEF**: 크롬 없이 완전 자동. CODEF 가입·키가 필요합니다(아래 "CODEF 키 발급", **[CODEF 설정…]**).
- 설정·상태 파일: `~/Library/Application Support/BankTaxReport/` (CODEF 키는 이 폴더의 `settings.json`, 본인만 읽기 권한).
  오류 기록은 같은 폴더의 `app.log`.
- 업데이트: 위 한 줄 명령을 다시 실행. 삭제: `uninstall_mac.command`.
- 맥 인증서 위치를 모르겠으면: 은행/홈택스 사이트에서 *인증서 내보내기(PC 저장)* 를 하면
  `~/Library/Preferences/NPKI/...` 아래에 `signCert.der`, `signPri.key` 가 생깁니다.

## 동작 방식

- **신한은행(화면 반자동)**: 앱 전용 크롬 프로필로 기업뱅킹을 엽니다. 인증서 창·키보드 보안은 자동 입력을
  막기 때문에 로그인은 사람이 하고, 로그인 뒤 메뉴 클릭과 엑셀 저장만 자동으로 합니다. 메뉴 글자 후보는
  `shinhan_browser.py` 위쪽에 모여 있어 은행 화면이 바뀌면 그 목록만 고치면 됩니다.
- **신한은행(CODEF, 선택)**: [CODEF](https://codef.io) — 금융 데이터 조회 API. 공동인증서를 등록하면 거래내역을 돌려줍니다.
  가입·키 발급 필요(개발용 `demo`는 무료, 일 조회 한도 있음).
- **홈택스**: [hometax](https://github.com/hjsh200219/hometax) — 공동인증서로 홈택스에 로그인해 세금계산서 목록을
  조회하는 오픈소스 도구. 무료, 별도 가입 없음. (비공식 도구라 홈택스 화면 규격이 바뀌면 멈출 수 있습니다.)

> "이체이력"은 은행의 *이체결과조회* 메뉴가 아니라 계좌 거래내역의 **출금 건**입니다. 받는 분·메모는
> `적요/받는분`, `메모` 열에 나옵니다.

## (참고) Windows 또는 명령줄로 쓰기

### 1. 설치 (처음 한 번)

1. **Python 3.12 이상** 설치: <https://www.python.org/downloads/> (설치 화면에서 *Add python.exe to PATH* 체크)
2. 이 `bank-tax-report` 폴더를 PC에 복사하고 `setup.bat` 더블클릭
   → 필요한 패키지를 설치하고 `.env` 파일을 만듭니다.

### 2. CODEF 키 발급 (은행 조회용, 처음 한 번)

1. <https://codef.io> 회원가입 → 로그인
2. 키 관리 화면에서 **Client ID / Client Secret / Public Key** 복사
3. 데모(개발) 버전으로 먼저 써 보고, 계속 쓸 거면 정식 서비스 신청 후 `CODEF_ENV=production`

### 3. `.env` 채우기

`.env`를 메모장으로 열어 채웁니다(예시는 `.env.example` 참고).

| 항목 | 설명 |
|---|---|
| `CODEF_CLIENT_ID` / `CODEF_CLIENT_SECRET` / `CODEF_PUBLIC_KEY` | 2단계에서 복사한 값 |
| `CODEF_ENV` | `demo` 또는 `production` |
| `CERT_DIR` | 법인 공동인증서 폴더. 보통 `C:\Users\<사용자>\AppData\LocalLow\NPKI\yessign\USER\cn=...` 처럼 생긴 폴더이고 안에 `signCert.der`, `signPri.key`가 있습니다. USB면 `E:\NPKI\...` |
| `CERT_PASSWORD` | 비워 두면 실행할 때 물어봅니다(권장) |
| `SHINHAN_ACCOUNTS` | 특정 계좌만 볼 때 `-` 없이 쉼표로. 비우면 보유 계좌 전체 |

인증서 종류: 은행·홈택스 둘 다 쓰려면 **범용 법인 공동인증서**가 필요합니다. 은행 전용(용도제한)
인증서는 홈택스에서, 전자세금용 인증서는 은행에서 거절될 수 있습니다. 그런 경우 두 인증서를
각각 쓰려면 `--skip-bank` / `--skip-hometax`로 나눠 실행하세요.

### 4. 실행

`run.bat` 더블클릭 → 비밀번호 입력 → `output\거래_세금계산서_YYYYMMDD-YYYYMMDD.xlsx` 생성.

명령창에서 옵션을 줄 수도 있습니다(맥 터미널이면 `run.bat` 대신 `python3 report.py`).

```bat
run.bat                                  :: 오늘 포함 최근 7일
run.bat --days 14                        :: 최근 14일
run.bat --from 2026-10-01 --to 2026-10-07
run.bat --skip-bank                      :: 홈택스만
run.bat --skip-hometax                   :: 은행만
run.bat --demo                           :: 가짜 데이터로 엑셀 모양만 확인 (인증서·인터넷 불필요)
```

처음 실행하면 CODEF에 신한은행 인증서가 등록되고 `connectedId`가 `.state.json`에 저장됩니다.
인증서를 갱신했으면 `.state.json`을 지우고 다시 실행하세요.

한쪽 조회가 실패해도 다른 쪽 결과로 엑셀을 만들고, 실패 이유를 **요약 시트**와 화면에 남깁니다
(이때 종료 코드 1).

### 매주 자동 실행 (선택, Windows)

Windows **작업 스케줄러** → 기본 작업 만들기 → 매주 월요일 09:00 → 프로그램 시작:
`py`, 인수 `-3 report.py`, 시작 위치 = 이 폴더. 무인 실행이면 `.env`에 `CERT_PASSWORD`를 넣어야 하므로
그 PC의 계정 보안을 확인하세요.

## 문제 해결

| 메시지 | 조치 |
|---|---|
| `CODEF 토큰 발급 실패` | Client ID/Secret, `CODEF_ENV`(demo/production) 확인 |
| `신한은행 공동인증서 등록 실패 CF-...` | 인증서 비밀번호, 인증서가 신한은행 기업뱅킹에 등록돼 있는지 확인. 메시지의 코드로 CODEF 문서 검색 |
| `지정한 경로에서 인증서를 찾지 못했습니다` | `CERT_DIR`이 `signCert.der`가 있는 폴더 자체인지 확인 |
| `개인 공동인증서 … 사업자 자료는 조회되지 않습니다` | 홈택스는 사업자(법인) 인증서로 로그인해야 합니다 |
| `hometax 도구가 설치되지 않았습니다` | 맥: 설치 명령 다시 실행 / Windows: `setup.bat` 다시 실행 |
