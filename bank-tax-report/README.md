# bank-tax-report — 신한은행 기업 거래·이체 + 홈택스 세금계산서 → 엑셀

법인 공동인증서 하나로 아래를 한 번에 조회해서 **엑셀 파일 1개**로 저장합니다(기본: 오늘 포함 최근 7일).

| 시트 | 내용 | 출처 |
|---|---|---|
| 요약 | 기간, 입금/출금 합계, 발급·수취 세금계산서 건수·공급가액·세액 | — |
| 계좌거래내역 | 신한은행 기업 수시입출 계좌 전체 거래 | 신한은행 (CODEF) |
| 이체(출금)내역 | 위 거래 중 출금 건 | 신한은행 (CODEF) |
| 세금계산서_발급(매출) | 같은 기간에 발급한 전자세금계산서 | 홈택스 |
| 세금계산서_수취(매입) | 같은 기간에 받은 전자세금계산서 | 홈택스 |

웹 앱이 아니라 **회사 PC(Windows)에서 실행하는 프로그램**입니다. 인증서 파일과 비밀번호가 PC 밖으로
나가는 곳은 CODEF(은행 조회용)와 홈택스뿐이고, 비밀번호는 어디에도 저장하지 않습니다.

## 왜 브라우저 자동 클릭이 아닌가

신한은행 기업뱅킹·홈택스 화면은 보안 프로그램(키보드 보안, 인증서 창)이 자동 입력을 막아서, 화면을
클릭하는 방식은 자주 깨집니다. 그래서 공동인증서로 직접 로그인하는 방식을 씁니다.

- **신한은행**: [CODEF](https://codef.io) — 금융 데이터 조회 API. 공동인증서를 등록하면 은행 거래내역을 돌려줍니다.
  은행 쪽은 CODEF 가입·키 발급이 필요합니다(개발용 `demo`는 무료, 일 조회 한도 있음).
- **홈택스**: [hometax](https://github.com/hjsh200219/hometax) — 공동인증서로 홈택스에 로그인해 세금계산서 목록을
  조회하는 오픈소스 도구. 무료, 별도 가입 없음. (비공식 도구라 홈택스 화면 규격이 바뀌면 멈출 수 있습니다.)

> "이체이력"은 은행의 *이체결과조회* 메뉴가 아니라 계좌 거래내역의 **출금 건**입니다. 받는 분·메모는
> `적요/받는분`, `메모` 열에 나옵니다.

## 1. 설치 (처음 한 번)

1. **Python 3.12 이상** 설치: <https://www.python.org/downloads/> (설치 화면에서 *Add python.exe to PATH* 체크)
2. **Git** 설치: <https://git-scm.com/download/win> (hometax 도구를 받는 데 필요)
3. 이 `bank-tax-report` 폴더를 PC에 복사하고 `setup.bat` 더블클릭
   → 필요한 패키지를 설치하고 `.env` 파일을 만듭니다.

## 2. CODEF 키 발급 (은행 조회용, 처음 한 번)

1. <https://codef.io> 회원가입 → 로그인
2. 키 관리 화면에서 **Client ID / Client Secret / Public Key** 복사
3. 데모(개발) 버전으로 먼저 써 보고, 계속 쓸 거면 정식 서비스 신청 후 `CODEF_ENV=production`

## 3. `.env` 채우기

`.env`를 메모장으로 열어 채웁니다(예시는 `.env.example` 참고).

| 항목 | 설명 |
|---|---|
| `CODEF_CLIENT_ID` / `CODEF_CLIENT_SECRET` / `CODEF_PUBLIC_KEY` | 2단계에서 복사한 값 |
| `CODEF_ENV` | `demo` 또는 `production` |
| `CERT_DIR` | 법인 공동인증서 폴더. 보통 `C:\Users\<사용자>\AppData\LocalLow\NPKI\yessign\USER\cn=...` 처럼 생긴 폴더이고 안에 `signCert.der`, `signPri.key`가 있습니다. USB면 `E:\NPKI\...` |
| `CERT_PASSWORD` | 비워 두면 실행할 때 물어봅니다(권장) |
| `SHINHAN_ACCOUNTS` | 특정 계좌만 볼 때 `-` 없이 쉼표로. 비우면 보유 계좌 전체 |

인증서 종류: 은행·홈택스 둘 다 쓰려면 **범용 법인 공동인증서**가 필요합니다. 은행 전용(용도제한)
인증서는 홈택스에서, 전자세금용 인증서는 은행에서 거절될 수 있습니다. 그런 경우 두 인증서를
각각 쓰려면 `--skip-bank` / `--skip-hometax`로 나눠 실행하세요.

## 4. 실행

`run.bat` 더블클릭 → 비밀번호 입력 → `output\거래_세금계산서_YYYYMMDD-YYYYMMDD.xlsx` 생성.

명령창에서 옵션을 줄 수도 있습니다.

```bat
run.bat                                  :: 오늘 포함 최근 7일
run.bat --days 14                        :: 최근 14일
run.bat --from 2026-10-01 --to 2026-10-07
run.bat --skip-bank                      :: 홈택스만
run.bat --skip-hometax                   :: 은행만
run.bat --demo                           :: 가짜 데이터로 엑셀 모양만 확인 (인증서·인터넷 불필요)
```

처음 실행하면 CODEF에 신한은행 인증서가 등록되고 `connectedId`가 `.state.json`에 저장됩니다.
인증서를 갱신했으면 `.state.json`을 지우고 다시 실행하세요.

한쪽 조회가 실패해도 다른 쪽 결과로 엑셀을 만들고, 실패 이유를 **요약 시트**와 화면에 남깁니다
(이때 종료 코드 1).

## 매주 자동 실행 (선택)

Windows **작업 스케줄러** → 기본 작업 만들기 → 매주 월요일 09:00 → 프로그램 시작:
`py`, 인수 `-3 report.py`, 시작 위치 = 이 폴더. 무인 실행이면 `.env`에 `CERT_PASSWORD`를 넣어야 하므로
그 PC의 계정 보안을 확인하세요.

## 문제 해결

| 메시지 | 조치 |
|---|---|
| `CODEF 토큰 발급 실패` | Client ID/Secret, `CODEF_ENV`(demo/production) 확인 |
| `신한은행 공동인증서 등록 실패 CF-...` | 인증서 비밀번호, 인증서가 신한은행 기업뱅킹에 등록돼 있는지 확인. 메시지의 코드로 CODEF 문서 검색 |
| `지정한 경로에서 인증서를 찾지 못했습니다` | `CERT_DIR`이 `signCert.der`가 있는 폴더 자체인지 확인 |
| `개인 공동인증서 … 사업자 자료는 조회되지 않습니다` | 홈택스는 사업자(법인) 인증서로 로그인해야 합니다 |
| `hometax 도구가 설치되지 않았습니다` | Git 설치 후 `setup.bat` 다시 실행 |
