조각JOGAK — 카드 노트 앱 시안

노트북에서 떠오른 단편적인 글을 잃어버리지 않도록, 한 조각씩 카드로 수집하고 폴더로 정리하는 앱. 노트북(데스크톱)과 모바일이 실시간으로 연동되어, 어디서 적어도 하나의 서랍에 모입니다.

1. 핵심 컨셉

이 앱이 지키는 세 가지 원칙
✂

글은 조각으로 태어난다

문서가 아니라 카드가 기본 단위. 제목 없이, 형식 없이, 한 문단이면 충분합니다. 긴 글은 나중에 조각을 이어 붙여 만듭니다.

⌗

정리는 서랍처럼

폴더는 깊은 트리가 아니라 얕은 서랍. 한 카드는 여러 서랍에 동시에 꽂힐 수 있고, 어디에도 꽂히지 않은 카드는 ‘미분류함’에 모입니다.

⇄

노트북과 한 몸

데스크톱 웹/앱에서 쓰던 글이 모바일에 즉시 나타납니다. 글로벌 단축키로 어떤 작업 중에도 카드 한 장을 바로 저장합니다.

충돌 없는 동기화

카드는 작게 쪼개져 있어 충돌이 드뭅니다. 같은 카드를 양쪽에서 고치면 두 버전을 나란히 보여주고 고르게 합니다. 오프라인 작성분은 연결 시 자동 병합.

내 데이터는 파일로

전체 조각을 Markdown + JSON으로 내보내기. 서랍은 폴더 구조 그대로 저장되어, 앱을 떠나도 데이터는 온전히 내 것입니다.

4. 사진 · 화면 캡처

사진은 사본 저장으로 확정 · 캡처는 핵심 기능으로 승격
사진 담기 — 확정안
사본 첨부 확정

드래그&드롭·파일 선택·붙여넣기로 사진 사본을 카드에 저장합니다. 맥의 파일 선택 창에서 사진 앱 미디어 브라우저를 통해 사진첩 사진을 고를 수 있습니다. 원본과 독립적이라 가장 확실하고, 기기 간 동기화도 앱이 책임집니다.

iCloud 공유 링크 보류

사본 방식으로 충분해 v1에서는 제외합니다. 저장 공간이 문제가 되면 나중에 다시 검토합니다.

사진첩 직접 참조 네이티브 단계

사본 없이 원본을 참조하는 방식은 iOS/맥 네이티브 앱 단계에서 PhotoKit으로 얹습니다. 그때는 사진 앱 공유 시트에서 바로 ‘조각으로 저장’도 가능해집니다.

화면 캡처 — 강화 기능
노트북 영역 캡처 ⌘⇧S

어떤 앱을 쓰고 있든 단축키를 누르면 십자 커서로 화면 영역을 지정해 바로 조각으로 저장합니다. 캡처한 앱 이름과 브라우저 URL이 출처로 자동 기록됩니다.

모바일 스크린샷 → 조각

스크린샷을 찍은 직후 공유 시트에서 ‘조각으로 저장’을 누르면 캡처 저장 화면(2-5)으로 진입합니다. 잠금화면·홈 위젯 버튼으로도 한 번에 캡처 저장에 들어갈 수 있습니다.

캡처 OCR 검색

캡처 속 글자를 자동으로 읽어(OCR) 카드와 함께 저장합니다. 이미지 조각도 텍스트처럼 검색되고, ‘글로 변환’ 버튼 한 번으로 순수한 글 조각이 됩니다.

정리하면 — 사진은 사본 저장으로 확정(iCloud 링크는 보류), 화면 캡처는 노트북 ⌘⇧S 영역 캡처 + 모바일 공유 시트 저장 + OCR 검색까지 v1 범위입니다. 홈 피드(2-1)의 사진 카드와 새로 추가된 캡처 저장 화면(2-5)을 참고하세요.
